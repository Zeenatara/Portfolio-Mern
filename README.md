# Zeenat Ara — Portfolio

## 🌐 Live Demo

[View Portfolio](https://portfolio-mern-mocha-zeta.vercel.app/)

## ✨ Features

* Responsive design
* About & Skills sections
* Featured projects
* GitHub project links
* Contact form
* Modern UI with animations

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* CSS
* Node.js
* Express.js
* Nodemailer

## ⚙️ Run Locally

```bash
git clone https://github.com/Zeenatara/Portfolio-Mern.git
cd Portfolio-Mern

cd client
npm install
npm run dev
```
